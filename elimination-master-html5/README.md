# 消除达人 - HTML5 版本

🎮 一款精美的三消+拼图玩法的限时消除游戏

## ✨ 游戏特色

- **简单易上手**: 点击两个相邻的相同图标即可消除
- **计时挑战**: 在限定时间内完成目标对数
- **道具系统**: 提示、移除、加时三大道具助你通关
- **100个关卡**: 从简单到困难的渐进式难度
- **星级评价**: 根据通关时间获得1-3星评价
- **数据存储**: 自动保存游戏进度
- **激励广告**: 看视频获得道具和双倍奖励

## 🎯 核心玩法

1. **开始界面**: 点击"开始游戏"进入关卡
2. **消除规则**: 点击两个相邻的相同图标即可消除
3. **目标要求**: 在时间耗尽前完成目标对数
4. **道具使用**: 使用道具获得帮助
5. **结算评价**: 根据用时获得星级评价

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript
- **框架**: 原生 JavaScript（无依赖）
- **存储**: LocalStorage
- **广告**: 微信激励视频广告

## 🚀 快速开始

### 方式一：直接打开
直接用浏览器打开 `index.html` 文件即可运行游戏

### 方式二：本地服务器
```bash
# 安装依赖
npm install

# 启动开发服务器
npm start
# 或
npm run dev
```

然后在浏览器访问: http://localhost:3000 或 http://localhost:8080

## 🔧 自定义配置

在 `index.html` 中可以修改以下配置：

```javascript

this.iconTypes = ['🍎', '🍊', '🍋', '🍇', '🍓', '🍉', '🍒', '🍌'];

// 关卡配置
if (level <= 5) {
    return { gridSize: 4, iconTypes: 4, timeLimit: 60, targetPairs: 8 };
}
```
