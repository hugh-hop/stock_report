## 1. 产品概述

像素风机甲对战小游戏 —— 一款复古像素风格的双人本地对战格斗游戏。两位玩家各操控一台像素机甲，在竞技场中通过移动、攻击、防御进行实时对战，直到一方血量归零判定胜负。

- 目标用户：喜欢复古像素风、休闲对战的玩家
- 核心价值：简单易上手、视觉风格鲜明、对战节奏紧凑

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 玩家1（蓝方机甲） | 键盘 WASD + J/K 操作 |
| 玩家2（红方机甲） | 键盘 方向键 + 数字键1/2 操作 |

### 2.2 功能模块
1. **战斗场景页面**：像素竞技场、双机甲对战、血量条、倒计时、胜负判定
2. **开始/结算页面**：游戏标题、开始按钮、操作说明、胜负结果展示

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 开始页面 | 标题区 | 像素风游戏标题动画 |
| 开始页面 | 操作说明 | 双方按键说明面板 |
| 开始页面 | 开始按钮 | 点击进入战斗 |
| 战斗场景 | 竞技场 | 像素风背景与地面，带视差滚动 |
| 战斗场景 | 机甲角色 | 两台像素机甲，支持移动/攻击/防御动画 |
| 战斗场景 | 血量条 | 双方HP条实时显示 |
| 战斗场景 | 倒计时 | 回合/总时间倒计时 |
| 战斗场景 | 特效层 | 攻击火花、防御光盾、受击闪烁 |
| 结算页面 | 胜负展示 | 显示胜者机甲与文字 |
| 结算页面 | 再来一局 | 重新开始按钮 |

## 3. 核心流程

1. 玩家进入开始页面，查看操作说明
2. 点击"开始战斗"进入战斗场景
3. 双方通过键盘操控机甲移动、攻击、防御
4. 攻击命中扣除对方血量，防御可减免伤害
5. 一方血量归零或时间耗尽时判定胜负
6. 显示结算页面，可选择再来一局

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝黑底色（#0a0a1a），搭配霓虹蓝（#00d4ff）与霓虹红（#ff3366）作为双方标识色
- **辅助色**：金黄（#ffd700）用于能量条/高亮，暗灰（#2a2a3a）用于UI面板
- **按钮风格**：像素风3D凸起按钮，带按压动画
- **字体**：像素风字体 "Press Start 2P"，小号8px用于UI，大号16px用于标题
- **布局风格**：全屏Canvas游戏画面，HUD叠加在Canvas上方
- **图标风格**：8-bit像素图标，无圆角

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 开始页面 | 标题区 | 像素风大标题，霓虹发光动画，星空背景粒子 |
| 开始页面 | 操作说明 | 双栏卡片，左蓝右红，像素边框 |
| 开始页面 | 开始按钮 | 金黄色3D像素按钮，hover放大+发光 |
| 战斗场景 | 竞技场 | 多层像素背景（远山/城市/地面），视差效果 |
| 战斗场景 | 机甲 | 16x24像素精灵，4帧行走/2帧攻击/1帧防御动画 |
| 战斗场景 | HUD | 顶部血量条（蓝/红），底部能量条，中央倒计时 |
| 结算页面 | 胜负展示 | 胜者机甲放大展示，霓虹文字，粒子庆祝效果 |

### 4.3 响应式
- 桌面优先设计，Canvas自适应窗口大小
- 保持像素比例不变形，使用 image-rendering: pixelated
- 最小支持 1024x600 分辨率

### 4.4 像素素材方案
- 所有角色与场景素材通过 Canvas API 程序化绘制（代码生成像素图案）
- 机甲精灵：16x24像素基础尺寸，2倍放大显示
- 场景瓦片：16x16像素，平铺拼接
- 特效粒子：4x4像素方块，带运动轨迹
- 无需外部图片资源，全部代码内联绘制
