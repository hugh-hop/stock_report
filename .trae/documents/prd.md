
# 消除达人 - 微信小游戏 - 产品需求文档

## 1. Product Overview
《消除达人》是一款面向 15-45 岁休闲游戏玩家的三消+拼图玩法限时消除微信小游戏，旨在通过碎片化时间娱乐和社交炫耀功能，结合激励视频广告（IAA）实现商业变现。

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 玩家 | 微信一键授权 | 游戏游玩、分享、查看排行榜 |

### 2.2 Feature Module
1. **开始界面**：游戏 Logo、开始按钮、每日礼包、音乐/音效开关
2. **关卡选择界面**：关卡列表、已解锁关卡、星级评价显示
3. **游戏主界面**：网格、计时器、目标显示、道具栏
4. **结算界面**：通关/失败动画、星级、奖励领取、下一关/重试
5. **广告系统**：激励视频广告、复活、双倍奖励、道具获取
6. **社交系统**：好友排行榜、分享功能
7. **成就系统**：成就收集、图鉴系统

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 开始界面 | Logo展示 | 游戏 Logo 和标题 |
| 开始界面 | 开始按钮 | 点击进入关卡选择 |
| 开始界面 | 每日礼包 | 每日首次进入时显示，看广告得奖励 |
| 开始界面 | 音乐开关 | 切换音效和背景音乐 |
| 关卡选择 | 关卡列表 | 显示已解锁关卡（1-999关） |
| 关卡选择 | 关卡状态 | 已通过/未解锁/当前关卡显示 |
| 关卡选择 | 星级评价 | 1-3 星显示通关评价 |
| 游戏主界面 | 网格系统 | 4x4 或 5x5 网格随机生成 |
| 游戏主界面 | 消除逻辑 | 点击选择，相同相邻图标消除 |
| 游戏主界面 | 计时系统 | 倒计时显示 |
| 游戏主界面 | 目标系统 | 剩余目标对数显示 |

| 结算界面 | 奖励领取 | 看视频得双倍奖励或直接领取 |
| 结算界面 | 复活/重试 | 失败后可看广告复活或直接重试 |

## 3. Core Process
玩家从开始界面进入，选择关卡后开始游戏，在限定时间内完成消除目标，通关后获得星级评价和奖励，失败可选择复活或重试，同时可通过分享和排行榜进行社交互动。

```mermaid
flowchart TD
    A[开始界面] --&gt; B[关卡选择]
    B --&gt; C[游戏主界面]
    C --&gt; D{是否通关?}
    D --&gt;|是| E[通关结算]
    D --&gt;|否| F[失败结算]
    E --&gt; G[下一关]
    E --&gt; B
    F --&gt; H[看广告复活]
    F --&gt; I[重试]
    H --&gt; C
    I --&gt; C
    B --&gt; A
    E --&gt; J[分享]
    F --&gt; J
```

## 4. User Interface Design

### 4.1 Design Style
- **主色调**：活力橙 (#FF6B35) + 清新蓝 (#4ECDC4)
- **辅助色**：温暖黄 (#FFE66D) + 柔和粉 (#FF9F1C)
- **按钮风格**：圆角设计，轻微阴影，悬停时有缩放效果
- **字体**：圆润可爱的无衬线字体，标题大号加粗，正文适中
- **布局风格**：卡片式布局，适度留白，层次分明
- **图标风格**：扁平化，色彩鲜明，有轻微描边

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 开始界面 | 整体布局 | 渐变背景，居中 Logo，按钮垂直排列 |
| 开始界面 | Logo区域 | 游戏标题 + 图标，有轻微浮动动画 |
| 开始界面 | 按钮区域 | 大尺寸开始按钮，下方是每日礼包和设置 |
| 关卡选择 | 顶部导航 | 返回按钮 + 标题 |
| 关卡选择 | 关卡网格 | 4xN 网格，每个关卡带星级/锁图标 |
| 游戏主界面 | 顶部状态栏 | 返回、关卡号、计时器、金币 |
| 游戏主界面 | 目标区域 | 目标显示条 |
| 游戏主界面 | 游戏网格 | 居中网格，有悬停和点击效果 |
| 游戏主界面 | 道具栏 | 底部横向排列道具按钮 |
| 结算界面 | 结果展示 | 大标题 + 星级 + 用时 |
| 结算界面 | 按钮区域 | 奖励领取按钮、下一关/重试按钮 |

### 4.3 Responsiveness
- 移动设备优先设计，支持主流手机屏幕尺寸
- 自适应刘海屏、全面屏
- 触摸优化，按钮尺寸适合手指点击

### 4.4 游戏元素设计
- **图标种类**：8 种水果/动物图标（苹果、香蕉、橙子、葡萄、草莓、西瓜、樱桃、柠檬）
- **消除效果**：缩放消失 + 粒子效果
- **计时动画**：最后 10 秒红色闪烁提醒
